Mundo Virtual

Este archivo es solo una portada. El mundo necesita el servidor Node.js (multijugador y guardado), así que no funciona abriendo un HTML con doble clic.

  1. En esta carpeta ejecuta npm install y luego npm start.
  2. Abre el mundo en la dirección de abajo.
Abrir http://localhost:3001

El cliente real está en public/index.html.
